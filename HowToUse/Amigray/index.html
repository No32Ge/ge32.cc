📘 AI Batch Pro 用户端使用指南

一、访问入口

打开浏览器访问：

xxxxxxxxxx
http://amigray.com/

你会看到一个深色风格的登录页面，标题为 "AI Batch Pro - 智能批量处理工作台"。

二、获取密钥（首次使用）

注意： 系统为了安全，密钥需要申请后由管理员批准。但为了演示方便，我们做了自动审批，申请后稍等片刻密钥就会自动出现。

步骤：

  1. 切换至「申请密钥」标签

    • 登录页面上方有两个标签：密钥登录 和 申请密钥
    • 点击 「申请密钥」

  2. 点击提交按钮

    • 页面会显示：提交申请后等待管理员审核
    • 点击 「提交申请」 按钮

  3. 等待密钥自动出现

    • 提交后页面会变成如下状态：

      xxxxxxxxxx
      ⏳ 申请已提交
      管理员正在审核您的申请...
      Key: ABP-XXXXXXXXXXXX

    • 稍等片刻（约3-5秒），系统会自动检测到密钥已批准

    • 页面会自动跳转到登录界面，并且密钥已经自动填入到输入框中 🎉

  4. 保存密钥（重要）

    • 密钥格式：ABP-XXXXXXXXXXXXXXXX（例如 ABP-A1B2C3D4E5F6G7H8）
    • 请务必复制保存好这个密钥，以后重新登录还需要用到
    • 密钥相当于您的账号密码，请勿泄露给他人

三、登录工作台

步骤：

  1. 输入密钥

    • 在「密钥登录」标签下，第一个输入框已自动填入刚才获取的密钥
    • 如果没有自动填入，请手动粘贴您保存的密钥

  2. 输入用户名（随便写）

    • 第二个输入框："设置您的用户名..."
    • 用户名可以是任意内容： 中文名、英文名、随便打几个字符都可以
    • 例如：张三、test、abc123、哈哈哈、!!! 都可以
    • 建议设置一个你自己好记的名字

  3. 点击「进入工作台」

    • 如果密钥有效，就会进入主工作台界面

五、完整使用流程

步骤 1：上传数据文件

在左侧面板 「1. 上传数据」 区域：

  1. 点击上传区域（虚线框，带 ☁️ 图标）
  2. 选择文件： 支持 .xlsx / .xls / .csv 格式的表格文件
  3. 设置表头行： 默认第1行是表头（如果你的表格表头在第2行，就改成2）
  4. 点击 「解析」 按钮

成功解析后：

  • 底部会显示文件的行数
  • 表头字段会以标签形式展示在下方
  • 系统提示：已加载 XX 行数据

提示： 表格的第一行应该是列名（表头），例如：商品名称、描述、价格 等

步骤 2：选择处理策略

在 「2. 选择处理策略」 区域：

  1. 点击下拉框，选择一个策略（例如：Listing撰写）

  2. 选择后下方会显示：

    • 策略说明： 介绍这个策略的用途
    • 必填字段： 标有橙色标签的字段名（你需要确保表格中有这些列）

  3. 系统会自动将表格列名与策略需要的字段进行匹配

步骤 3：字段映射

在 「3. 字段映射」 区域：

系统会自动尝试匹配字段，例如：

xxxxxxxxxx
商品名称 ──→ [下拉选择: 商品名称 ✓]
描述     ──→ [下拉选择: 描述     ✓]
  • 如果自动匹配成功（绿色 ✓），无需操作
  • 如果自动匹配失败（红色 ⚠️），需要手动从下拉框中选择对应的列
  • 所有字段都必须映射完成，按钮才会变成蓝色

点击「验证并准备执行」

  • 验证通过后系统会提示：验证通过，准备就绪

步骤 4：选择AI模型（可选）

在 「4. 选择AI模型」 区域：

  • 默认是 自动选择(默认)
  • 如果管理员配置了多个AI模型，你可以在这里选择
  • 不同模型消耗的额度不同（显示为 ×2 额度/条）
  • 一般保持默认即可

步骤 5：执行批量处理

点击右下角的圆形播放按钮 ▶

  • 按钮会变为红色停止图标，表示正在执行

  • 中间聊天区域会显示进度条：

    xxxxxxxxxx
    ┌──────────────────────────────┐
    │  Listing撰写                  │
    │  Progress: 15 / 100    15%   │
    │  ████████░░░░░░░░░░░░░░░░░░  │
    │  ✓ 15  ✗ 0                  │
    └──────────────────────────────┘

  • 顶部状态栏会显示：Processing 15/100

执行完成后：

  • 进度条变满，显示完成信息

  • 出现导出按钮：

    xxxxxxxxxx
    [📊 Export Excel]  [📄 Export JSON]

  • 额度会自动扣减

六、导出结果

处理完成后，有两种方式导出结果：

方式一：导出 Excel

  • 点击 「📊 Export Excel」 按钮
  • 会自动下载一个 .xlsx 文件
  • 可以用 Excel / WPS 打开查看

方式二：导出 JSON

  • 点击 「📄 Export JSON」 按钮
  • 会自动下载一个 .json 文件
  • 适合开发者进行二次处理
