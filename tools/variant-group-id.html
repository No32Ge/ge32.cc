变体组ID + 单位换算 · 主变体随机

SKU + 父SKU → 自动生成 Variant Group ID 和 Is Primary Variant (多SKU组内随机非首位) · 重量(g→lb) · 尺寸(cm→英寸)
📌 处理逻辑（输入列仅需：SKU, 父SKU, 重量(g), 长, 宽, 高）
• Variant Group ID : 父SKU为空 → 组ID=SKU；父SKU存在 → 相同父SKU下所有SKU共用一个组ID(等于组内首个SKU)。
• Is Primary Variant : 每个 Variant Group 内：若仅1个SKU → 标记为 "Yes"；若≥2个SKU → 从第二个及以后的SKU中随机选择一个标记为 "Yes"，其余为 "No" (避免首位被自动设为主变体，实现差异化)。
• 重量(g) → netContentStatement : 克转英镑 (1g = 0.00220462 lb)，保留2位小数。
• 长 / 宽 / 高 (cm) → assembledProductLength/assembledProductWidth/assembledProductHeight/ : 厘米转英寸 (1cm = 0.393701 in)，保留2位小数。
✅ 输入Excel必须包含列：SKU, 父SKU, 重量(g), 长, 宽, 高 (列名不区分大小写，支持中英文变体)
