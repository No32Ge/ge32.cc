📌 过滤规则（优先级最高）
💡 三个数值计算逻辑（符合沃尔玛定义）
• Number of Pieces (件数) : 所有物品数量总和（不同物品数量相加）
• Count Per Pack (每包数量) : 单物品 = 该物品数量；多物品套装 = 1（每种物品每包各1件）
• Total Count (总数量) : 单物品 = 物品数量；多物品套装 = 1（整体视为一个组合包）
📘 参考案例：礼品篮5种不同物品 → 件数=5，每包数量=1，总数量=1；药丸x50 → 件数=50，每包=50，总数=50
